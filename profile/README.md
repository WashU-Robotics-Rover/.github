# WashU Robotics Rover

Student team at Washington University in St. Louis competing in the University Rover Challenge.

[Team page](https://washurobotics.com/Projects/rover)

## Teams

- **leadership** — rover captain and subteam leads. Maintain access on team repositories.
- **software** — onboard software, ROS 2, autonomy, and teleoperation.
- **electrical** — power, communications, and embedded electronics.
- **mechanical** — chassis, suspension, arm, and fabrication.
- **science** — University Rover Challenge science mission.
- **all-devs** — every rover member. Baseline read and issue-triage access.

Subteams sit under `all-devs`, so subteam members keep that baseline access. Software has write access on the rover software repositories. Organization owners create repositories and teams.

## Repositories

Current software work belongs in the private `grizzly` repository. `grizzly-mvp-26` is the previous working tree. [grizzly-25-26](https://github.com/WashU-Robotics-Rover/grizzly-25-26) is the public history of the 2025-26 season.

This `.github` repository holds the organization profile and the default contributing, security, and issue templates used by repositories that do not define their own.
